# Wiki source

These files are the source of the [GitHub wiki](https://github.com/uuur86/strobj/wiki).
Edit them here so that documentation changes are reviewed with the code.

The [Publish wiki](../../.github/workflows/wiki.yml) workflow publishes this
directory automatically whenever a change to it is pushed to `master` or to a
development branch (`*.x-dev`). You can also run it manually from the Actions tab.
The wiki mirrors this directory: pages edited only on the wiki are replaced or
removed by the next publish, and this README is not published.

Links between pages use wiki page names (for example `Getting-Started`), so they
resolve on the wiki rather than in this directory.
